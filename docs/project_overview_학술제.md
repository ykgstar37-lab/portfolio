## 1. 프로젝트 소개

서울시의 6개 카테고리 문화 및 여가시설(공연시설, 박물관/유적지, 공원, 방탈출, 영화관, 전통사찰)의 **공간적 분포를 분석**하여, 지역별 문화 접근성과 분포 불균형을 정량적으로 파악한 학술 프로젝트입니다.

### 핵심 가치

| 가치 | 설명 |
|------|------|
| **공간 분석** | 법정동/행정동/시군구 다단계 지역 단위 분석 |
| **다면적 조사** | 6개 시설 카테고리를 통합 비교 분석 |
| **데이터 기반** | 공공데이터를 활용한 정량적 현황 파악 |

## 5. 분석 방법론

### 분석 흐름

```
공공데이터 수집 (5개 원본 CSV)
    ↓
데이터 정제
    ├── 서울특별시 데이터 필터링
    ├── 영업 상태 필터링 (영화관: "영업중")
    ├── 카테고리 필터링 (공원: "공원" 포함 / 방탈출: "방탈출" 포함)
    └── 필요 컬럼 추출
    ↓
지역 단위 집계
    ├── 법정동(Dong) 단위 시설 개수 집계
    ├── 행정동(Administrative Dong) 단위 집계
    └── 시군구(Gu) 단위 합계 집계
    ↓
시설별 분포 결과 산출 (6개 df_*.csv)
    ↓
보고서 및 발표 자료 작성
```

## 9. 결론 및 시사점

본 프로젝트는 서울시 문화·여가시설의 공간적 분포를 분석하여:

1. **강남구**가 공연시설, 영화관, 방탈출, 전통사찰 등 대부분 카테고리에서 최다 시설 보유
2. **중구**가 박물관/유적지에서 압도적 1위 (역사문화 중심지)
3. **서초구**가 공원 시설에서 최다 (녹지 환경 우수)
4. 시설 유형에 따라 **지역별 분포 패턴이 상이**함을 정량적으로 확인

이러한 분석은 문화시설 접근성 평가, 지역 간 문화 격차 파악, 향후 시설 계획의 기초자료로 활용 가능합니다.
