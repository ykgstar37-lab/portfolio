## 한 줄 소개

> 서울시 6개 카테고리 문화·여가시설의 공간적 분포를 법정동/행정동/시군구 단위로 분석하여 지역별 문화 접근성과 분포 불균형을 정량적으로 파악한 학술 연구

---

## 프로젝트 배경 및 문제 정의

- 서울시 문화·여가시설의 지역별 분포 현황에 대한 체계적 분석 부재
- 지역 간 문화 접근성 격차에 대한 정량적 데이터 필요
- 공공데이터를 활용한 데이터 기반 현황 조사의 필요성

---

## 기술 스택

```
분석 언어    R
핵심 패키지  dplyr (필터링, 그룹화, 집계)
데이터       공공데이터 5종 (공연, 영화관, 문화시설, 박물관, 전통사찰)
분석 대상    6개 카테고리 (공연시설, 박물관/유적지, 공원, 방탈출, 영화관, 전통사찰)
지역 단위    법정동, 행정동, 시군구
```

---

## 분석 진행 과정

### 1단계 — 데이터 수집 및 정제
- 5개 공공데이터 CSV 파일 수집 (총 8MB+)
- 서울특별시 필터링, 영업 상태 필터링, 카테고리 필터링
- 법정동/행정동/시군구 단위 매핑

### 2단계 — 시설별 분포 분석
- 6개 카테고리별 독립 분석 스크립트 작성
- 법정동 → 시군구 단위 집계 파이프라인
- 시설별 지역 분포 결과 데이터셋 생성

## 핵심 성과 및 기여

### 데이터 파이프라인
- 5종 공공데이터 → 6개 카테고리별 정제 → 시군구 단위 통합 집계
- R dplyr 기반 필터링-그룹화-집계 파이프라인 설계

### 분석 결과
- 서울시 25개 자치구의 **문화시설 분포 불균형** 정량적 확인
- 시설 유형별 **지역 특화 패턴** 도출 (강남구=상업 여가, 중구=역사문화, 서초구=녹지)
- 6개 카테고리 통합 비교를 통한 **다면적 문화 접근성** 분석

### 산출물
- 최종 연구 보고서 + 발표 자료 (PDF/PPTX) 작성

## 기술적 도전과 해결

| 문제 | 원인 | 해결 |
|------|------|------|
| 지역 단위 불일치 | 데이터마다 법정동/행정동 혼재 | 행정동-시군구 매핑 테이블로 통일 |
| 카테고리 분류 | 문화시설 통합 데이터에서 세부 분류 필요 | FCLTY_NM, CTGRY_THREE_NM 필드 기반 키워드 필터링 |
| 영업 상태 혼재 | 폐업/휴업 시설 포함 | "영업중" 필터링으로 현행 시설만 추출 |

## 아키텍처

```
[공공데이터 5종 CSV]
  공연시설 / 영화관 / 문화활동시설 / 박물관 / 전통사찰
    ↓
[데이터 정제]
  서울 필터 → 영업상태 필터 → 카테고리 필터 → 컬럼 추출
    ↓
[지역 단위 집계]
  법정동/행정동 → group_by + summarise → 시군구 합산
    ↓
[결과 데이터셋 6종]
  df_perform / df_movie / df_공원 / df_방탈출 / df_박물관유적지 / df_temple
    ↓
[보고서 + 발표 자료]
```

## 배운 점

- **공공데이터 정제** 실무 경험 (이질적 데이터 소스 통합, 행정구역 매핑)
- R dplyr를 활용한 **데이터 파이프라인** 설계 및 구현
- 다면적 카테고리 비교 분석을 통한 **데이터 기반 의사결정** 역량 강화
- 분석 결과를 보고서 및 발표 자료로 **커뮤니케이션**하는 경험
