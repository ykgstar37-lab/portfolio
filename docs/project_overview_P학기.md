# 암호화폐 변동성 비교 및 분석: GARCH 모델을 기반으로 한 예측 — 프로젝트 전체 개요

> P학기 (통계 실무 프로젝트) | 6조 52경

---

## 1. 프로젝트 소개

비트코인의 변동성을 예측하기 위해 **HAR 구조**와 **TGARCH 비대칭 효과**를 결합한 모델을 구축하고, 거래량(Volume) 및 공포-탐욕 지수(FNG) 같은 **외생변수(Exogenous Variables)**를 추가하여 예측 성능 향상을 실증적으로 분석한 연구 프로젝트입니다.

**최종 목표**: 어떤 모형에서 비트코인 변동성이 가장 잘 예측되는가? 특히 외생변수가 예측력을 향상시키는지 실험적으로 확인하는 것.

### 핵심 가치

| 가치 | 설명 |
|------|------|
| **다중 모형 비교** | GARCH, TGARCH, HAR-GARCH, HAR-TGARCH, HAR-TGARCH-X 5개 모형 체계적 비교 |
| **비대칭 효과** | TGARCH(GJR-GARCH)로 폭락 시 변동성 비대칭(레버리지 효과) 반영 |
| **외생변수 실증** | Volume + FNG 지수 추가 시 예측력 향상 여부 검증 |

## 4. 분석 방법론

### 분석 흐름

```
원본 데이터 수집 (비트코인 가격, FNG, 거래량)
    ↓
데이터 전처리 (콤마 제거, float 변환, 로그수익률 계산)
    ↓
사전 검정
    ├── ADF 검정 (단위근 → 정상성 확인)
    ├── ARCH-LM 검정 (이분산성 → GARCH 필요성 확인)
    └── 정규성 검정 (normaltest)
    ↓
5개 모형 적합 및 1-step ahead 예측
    ├── GARCH(1,1)
    ├── TGARCH (GJR-GARCH(1,1,1))
    ├── HAR-GARCH (HARCH, lags=[1,7,30])
    ├── HAR-TGARCH (HAR + 비대칭 TGARCH)
    └── HAR-TGARCH-X (+ Volume + FNG 외생변수)
    ↓
성과 평가 (MSE, RMSE, MAE, MAPE, R²)
    ↓
모형 간 비교 → 최적 모형 선정
```

### 모형 상세

| 모형 | 평균식 | 분산식 | 특징 |
|------|--------|--------|------|
| **GARCH(1,1)** | Zero | σ²ₜ = ω + α·r²ₜ₋₁ + β·σ²ₜ₋₁ | 기본 변동성 모형 |
| **TGARCH** | Zero | + γ·r²ₜ₋₁·I(rₜ₋₁<0) | 하락 시 변동성 비대칭 반영 |
| **HAR-GARCH** | Zero | HARCH(1,7,30) | 단·중·장기 변동성 구조 |
| **HAR-TGARCH** | OLS | r1 + r7 + r30 + neg + σ_lag | HAR + 비대칭 결합 |
| **HAR-TGARCH-X** | OLS | + Volume + FNG | 외생변수 추가 |

### 통계 검정

| 검정 | 목적 | 결과 |
|------|------|------|
| **ADF (Augmented Dickey-Fuller)** | 시계열 정상성 확인 | 원시 가격: 비정상 → 로그수익률: 정상 |
| **ARCH-LM** | 이분산성(ARCH 효과) 확인 | p < 0.05 → GARCH 모형 사용 근거 |
| **정규성 검정** | 수익률 분포 확인 | 정규성 기각 → 두터운 꼬리 확인 |

## 6. 주요 분석 결과

### 사전 검정 결과

| 검정 | 대상 | 결과 | 해석 |
|------|------|------|------|
| ADF (1차) | 원시 가격 | 비정상 | 단위근 존재 → 차분 필요 |
| ADF (2차) | 로그수익률 | **정상** | 정상성 확보 → 모형 적합 가능 |
| ARCH-LM | 로그수익률 | **유의** | ARCH 효과 존재 → GARCH 류 모형 적합 |
| 정규성 | 로그수익률 | **기각** | 두터운 꼬리 → t-분포 고려 |

### 모형 비교 (1-step ahead 예측, 2023.01~2023.11)

| 모형 | 평가 지표 |
|------|-----------|
| GARCH(1,1) | MSE, RMSE, MAE, MAPE, R² |
| TGARCH (GJR-GARCH) | MSE, RMSE, MAE, MAPE, R² |
| HAR-GARCH | MSE, RMSE, MAE, MAPE, R² |
| HAR-TGARCH | MSE, RMSE, MAE, MAPE, R² |
| HAR-TGARCH-X (Volume+FNG) | MSE, RMSE, MAE, MAPE, R² |

### 핵심 발견

- **TGARCH**의 레버리지 효과(γ): 비트코인 하락 시 변동성이 상승 시보다 크게 증가
- **HAR 구조**(1일/7일/30일)가 단·중·장기 변동성 패턴을 효과적으로 포착
- **외생변수(Volume + FNG)**: 서로 보완적 정보 제공 (거래 활동 강도 vs 시장 심리)
- **FNG 지수**가 비트코인 수익률의 유의미한 예측 지표임을 확인

## 8. 결론 및 시사점

본 연구는 비트코인 변동성 예측을 위해 5개 모형을 체계적으로 비교하여:

1. **GARCH → TGARCH**: 비대칭 레버리지 효과 반영으로 하락 변동성 포착 개선
2. **HAR 구조**: 단기(1일)/중기(7일)/장기(30일) 변동성의 다중 스케일 분석
3. **외생변수(Volume + FNG)**: 거래량(시장 활동 강도)과 심리지수(공포/탐욕)가 보완적 정보를 제공하여 예측력 향상 가능성 확인
4. **통계적 사전 검정**(ADF, ARCH-LM)을 통한 모형 적용 근거 확보

이러한 분석은 암호화폐 투자 리스크 관리 및 변동성 기반 트레이딩 전략 수립에 활용 가능합니다.
