## 한 줄 소개

> GARCH, TGARCH, HAR-GARCH, HAR-TGARCH, HAR-TGARCH-X 5개 모형을 비교하여 비트코인 변동성 최적 예측 모형을 탐색하고, 외생변수(Volume+FNG)의 예측력 향상 기여도를 실증 분석한 연구

## 프로젝트 배경 및 문제 정의

- 한국 가상자산 시장 규모 300조 원 돌파(2021), 20~30대 투자자 비율 73%
- 루나 사태, 정부 규제 등 예측 불가한 폭락으로 청년 투자자 피해 발생
- 비대칭 변동성(하락 시 변동성 급증)을 반영하는 예측 모형의 필요성
- 기존 GARCH 단독 모형의 한계 → HAR 구조 + 외생변수 결합 실험 필요

## 분석 진행 과정

### 1단계 — 데이터 전처리 및 사전 검정
- 비트코인 가격 → 로그수익률(log return) 변환
- **ADF 검정**: 원시 가격 비정상 → 로그수익률 정상성 확보
- **ARCH-LM 검정**: 이분산성(ARCH 효과) 존재 확인 → GARCH 류 모형 적합 근거
- **정규성 검정**: 두터운 꼬리 확인 → t-분포 고려

### 2단계 — 5개 모형 적합 및 비교
- **GARCH(1,1)**: 기본 조건부 분산 모형
- **TGARCH (GJR-GARCH)**: 음수 수익률 indicator로 비대칭 레버리지 효과 반영
- **HAR-GARCH**: HARCH(1,7,30)로 단·중·장기 변동성 구조 포착
- **HAR-TGARCH**: HAR + 비대칭 효과 OLS 결합
- **HAR-TGARCH-X**: Volume + FNG 외생변수 추가하여 예측력 향상 실험

### 3단계 — 1-step ahead 예측 및 성과 평가
- 2023.01~2023.11 구간 1-step ahead 조건부 분산 예측
- MSE, RMSE, MAE, MAPE, R² 5개 지표로 모형 간 비교

## 주요 결과

| 분석 항목 | 결과 |
|-----------|------|
| **ADF 검정** | 로그수익률 정상성 확인 (p < 0.05) |
| **ARCH-LM 검정** | ARCH 효과 존재 → GARCH 모형 적합 근거 |
| **TGARCH 레버리지** | γ = 0.0990 → 하락 시 변동성 추가 증가 확인 |
| **HAR 구조** | 1일/7일/30일 다중 스케일 변동성 포착 |
| **외생변수** | Volume + FNG → 보완적 정보 제공 (거래 강도 vs 시장 심리) |

## 핵심 성과 및 기여

### 모형 설계
- GARCH → TGARCH → HAR-GARCH → HAR-TGARCH → HAR-TGARCH-X **5단계 모형 발전 구조** 설계
- 조건부 분산 재귀 함수(SIG) 직접 구현 (GARCH/TGARCH 재귀식)
- HAR 설명변수(r1, r7, r30) 수작업 생성 + OLS 적합

### 통계 검정
- ADF → ARCH-LM → 정규성 검정의 **체계적 사전 검정 파이프라인** 구축
- 검정 결과를 근거로 모형 선택의 통계적 정당성 확보

### 외생변수 분석
- Volume(시장 활동 강도)과 FNG(시장 심리)의 **다중공선성 체크** 후 동시 투입
- 조건부 효과 해석: 동일 심리 수준에서의 거래량 효과, 동일 거래량에서의 심리 효과 분리

## 기술적 도전과 해결

| 문제 | 원인 | 해결 |
|------|------|------|
| 비정상 시계열 | 가격 데이터 단위근 존재 | 로그수익률 변환 → ADF 검정으로 정상성 확인 |
| 모형 수렴 불안정 | 수익률 스케일이 너무 작음 | RET_SCALE(×10, ×100) 적용 + 분산 초기값 설정 |
| 비대칭 변동성 | 하락 시 변동성이 상승 시보다 큼 | TGARCH의 음수 indicator(γ) 항으로 레버리지 효과 반영 |
| 외생변수 중복 우려 | Volume과 FNG 동시 투입 | 상관관계 확인 → 보완적 정보로 판단 후 동시 사용 |
| 평균구조 잔존 | GARCH에 평균구조가 남으면 가짜 변동성 발생 | mean='Zero' 설정 또는 AR 잔차 추출 후 분산 모형 적합 |

- **외생변수 투입** 시 다중공선성 체크 및 조건부 효과 해석 기법
- Python `arch` 패키지를 활용한 금융 변동성 모형 구현 및 재귀 함수 직접 작성
